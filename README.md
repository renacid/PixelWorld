# ピクセルワールド — 草原の迷宮

宝箱4種類・敵ごとのドロップ・隠し罠6種類の設定手順は [LOOT_AND_TRAPS.md](LOOT_AND_TRAPS.md) を参照してください。

iPhoneの縦画面を優先した、Canvas描画のターン制ダンジョンゲームです。TypeScript + Vite。ゲーム用の外部API、CDN、フォント、画像素材は使用していません。ビルド後は静的ファイルだけで動作します。

## 起動

Node.js 22.18以上を使用してください。設定ファイルはNodeのネイティブTypeScript読み込みを使用し、制限された環境でも親フォルダの探索が不要な構成にしています。

```sh
npm install
npm run dev
```

表示されたローカルURLを開きます。同じWi-FiのiPhoneでは、開発PCのLANアドレスと表示されたポートでアクセスできます。ファイアウォールで開発サーバーの接続許可が必要になる場合があります。

```sh
npm test       # ゲームロジックのテスト
npm run build # 型検査と静的ファイルの生成
npm run preview
```

## 遊び方

- ソロプレイから平原を選びます。踏破すると次の平原が解放されます。
- 開始直後に下へ進むと、アタックとランダムワープ入りの宝箱があります。火球・雷・風のいずれかが入った宝箱はマップの別の場所にあります。火雨は東側の宝箱です。
- 宝箱に移動すると開きます。古代の記録は独立した石板として床に置かれています。出口は階段のマスです。
- スキルを選択 → 方向キーで照準 → 発動。発動可能な場合だけマップ内の下部に発動ボタンが表示されます。同じスキルを再タップすると選択解除します。
- バッグはいつでも配置変更できます。操作はドラッグまたは一覧を選んでマスタップ。回転・バッグ外への保管も可能です。
- 待機は1行動。移動・待機を合計5行動するとMPが3回復します。スキル使用は回復カウントを進めません。
- 道具は3枠。満杯なら床に残り、同じマスで空き枠ができると拾えます。
- 千里眼薬（小）を取得するたび視野が2ずつ広がり、マップをドラッグしてカメラを動かせます。カメラを動かしてもプレイヤーの視界は移動しません。
- 精霊の種で自動行動する味方を召喚できます。
- 矢印 / WASD：移動・照準、1〜9：配置済みスキルを選択、Enter：発動、Space：待機、B：バッグ、M：地図。

## 決定済みの仕様・仮設定

- 初期HP30・MP20・基礎攻撃力10・会心15%・会心倍率1.5。
- 移動入力では攻撃しません。アタックは物理・前方1マス・50〜70%の一様乱数・MP1・CT0。
- 火球：100% / MP3 / CT1 / 射程5。雷：130% / MP6 / CT3 / 射程4。風：70% / MP4 / CT2 / 射程4。
- 火雨：自分を除く5×5の24マス / 30%×3ヒット / MP10 / CT10。壁マスは対象外。頭上から降る攻撃として、範囲内の壁越しの床にも届きます。大型の敵も1ヒットにつき1回だけダメージを受けます。
- 同種スキルは1ブロック。重複取得で基礎レベルのみ増加。基礎・実効レベルに上限は設けず、1レベルごとに5%加算。
- 火球と火雨を辺で連結すると、両方の実効レベル+1。
- 炎＋雷は即爆破し、起爆した実ダメージ（会心・レベル補正込み）の120%を追加。両属性を消去。複数ヒットは順次処理し、その後のヒットでは再付着。
- 風散は元の敵の占有セル周辺1マス（斜め含む）に、起こしたヒットの10%ダメージと元属性を付着。反応した元属性と風は消費。1回の風散から再度の風散は起きず、周辺の敵の爆破は可能。
- 最終ダメージは切り捨てで整数化。弱い風散を常に1以上へ切り上げる処理はありません。
- 付着は10行動保持。付けた行動では減らさず、次の行動からカウント。同属性は10へ更新。3種類目の非反応属性は最も古く付着した属性を置換。
- CTは発動行動の終了時には減らさず、以降の各プレイヤー行動で1減少。CT1なら次の1行動を終えると再使用可能。
- 壁・敵への移動、不足MP、未回復CT、効果のない回復アイテムは行動を消費しません。方向の照準変更も無料です。
- 平原4〜5の炎床は設置効果のサンプル。プレイヤーが入ると3ダメージ＋炎。新しい設置型スキルは未追加。
- ステージ終了後は再開不可。次の出発時にはスキル・道具・能力を初期化し、踏破状況だけ引き継ぎます。

## 保存

localStorageへステージ開始、各行動終了、バッグ確定、中断、画面を閉じるときに保存します。途中でブラウザを閉じても「続きから」で再開できます。スキル配置画面の途中なら、直前の確定状態から配置画面を再表示します。

保存形式はバージョン付き。読めないデータを検出した場合は案内を表示し、新しい冒険を開始できます。保存不可の場合もゲームは動作し、保存警告を表示します。ブラウザデータの削除や別ブラウザへの移動では復元できません。

## GitHub Pages

`vite.config.ts` は `base: './'` を使用し、リポジトリ名付きのサブパスに対応しています。`dist/` の内容をGitHub Pagesへ配置してください。ハッシュルーター等のサーバー設定は不要です。

付属の `.github/workflows/pages.yml` を使う場合、GitHubにリポジトリを作成してpushし、Settings → Pages → Source を GitHub Actions に設定後、ActionsからDeploy Pagesを手動実行します。自動の公開は行いません。

## 構造と拡張箇所

- **敵を追加・調整する場所：`src/data/enemies.ts`**。名前・能力・サイズ・索敵・追跡・MP・スキル・絵のIDと倍率を集約しています。敵IDの型も自動生成されます。
- 出現数と固定位置は`src/stages/index.ts`の`enemySpawns`で設定。既存の絵とスキルを使う敵は、この2ファイルだけで追加できます。
- `enemySkills.ts`はスキルそのものの効果定義、`SpriteAtlas.ts`は絵の内容を担当します。

詳しい地形・森ステージ・ドット絵の追加方法は [EXTENDING.md](EXTENDING.md) を参照してください。既存プログラムにも役割の説明コメントを記載しています。

- ランダムワープ：MP7 / CT30 / バッグ2×2。周囲9×9の空き床へ移動（隣接8マスを除外）。
- ログ：マップ左下に約3秒表示しフェードアウト。ログボタンで過去100件を参照。
- 敵の追跡：攻撃せず12行動追跡すると1行動スキップ。30%の抽選でスキップ状態を解除し、失敗なら残り1で次の行動も再抽選。全対象が索敵距離外なら敵視を解除します。
- 通常画面の地形の薄い表示を削除。11×11の外周半マスの見切れは維持しています。

- `src/game/GameSession.ts`：UIに依存しないセッション。`Command.ts`：コマンドと将来の対戦通信インターフェース。乱数カーソルと開始シードを保存。
- `src/game/TurnManager.ts`：味方・敵の行動後にCT/属性/MPを更新。MP回復の調整値。ドロップ率は`data/enemies.ts`の各敵で設定。
- `src/skills/`：配置検証、連結探索、射線、属性反応。定義はactive/passiveの区分を持ち、実効レベルに将来のパッシブ補正を渡せます。
- `src/actors/Actor.ts`：占有セル・移動方向・攻撃セル。1/4/9マスの正方形のみをサポート。
- `src/ai/EnemyAI.ts`：索敵・巡回・追跡・最後に見た場所への移動。味方も同じ行動基盤を使用。
- `src/stages/index.ts`：平原1〜5のステージ定義。`MapState.ts`で通行可能な地形・宝箱・敵を生成。
- `src/render/GameCanvas.ts`：32pxタイル、16px基本キャラを整数倍率で描画。ダメージ・攻撃・撃破・ミニマップを描画。
- `src/main.ts` / `src/style.css`：モバイル向けUI。

対戦モードは準備中表示と通信インターフェースのみ。実通信・30行動同期・妨害アイテム・対戦バフは未実装です。効果音はWeb Audioで実装し、設定メニューで切り替えられます。ゲームバランスは初期調整段階です。

ステージの編集方法は [地域・階層設定ガイド](src/stages/README.md) を参照してください。
