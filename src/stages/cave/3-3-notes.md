# 崩落した遺跡 3-3

工房から開くデータは `3-3.json`。プレイ用は `3-3.ts`。
工房で編集したらJSONとTypeScriptをそれぞれ出力して更新する。

- 1層：ユーザー作成の地形・配置・抽選設定を保持。
- 2層「地下水路と採掘跡」：70×40。西から東へ進む。中央の水没区画を上下ルートと細い橋で回り込み、離れた2つの巣穴を破壊して昇降路へ。上側の採掘拠点に宝物庫の鍵、下側に地下植物群。北東の宝物庫は鉄扉で施錠。
- 3層「沈黙の環状神殿」：50×56。南から開始。左右の回廊と中央祭壇で3枚の古代の記録を回収して北へ。西は石像、東はゴブリンの占拠区画、北東は水が入り込んだ植物群。南西の宝物庫へ戻る寄り道も可能。

新規階層は各2個の宝石を固定配置。追加の罠・敵・宝箱は階層設定で調整可能。
3-3以降のランダム道具は `loot.itemCategories` のHP/MP/その他=4/4/2を継承。
比率の既定値は `DungeonRules.ts`、分類内の補助道具の重みは `data/loot.ts` の `SUPPORT_ITEMS`。
鍵・初期宝箱・ボス戦旗などの確定報酬は分類抽選の対象外。
