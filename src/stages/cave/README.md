# 洞窟 3-1〜

3-1〜3-5を実装済みです。地域共通設定は `../regions.ts` の `cave`。
各番号の `.ts` がゲーム用、`.json` がダンジョン工房から開く編集用データです。
工房で編集した場合はJSONとTypeScriptの両方を保存してください。

## 3-5：地底に眠る古木

| 層 | 大きさ | 敵の基準倍率 | 内容 |
| --- | --- | --- | --- |
| 1 | 44×40 | 1.0 | 熔脈の坑道。ボムストーンと石スライム |
| 2 | 46×42 | 1.3 | 地下水と草地。蝶と結晶花 |
| 3 | 48×44 | 1.6 | 木と大結晶花が増える根の回廊 |
| 4 | 44×72 | 1.9 | 探索区画と、上側に接続した縦長の古木の祭壇 |

`floorSettings[層].enemyMultiplier` は基礎値への総倍率です。エルダー・トレントは
固定HPの段階移行に合わせてHP500・MP100・攻撃5を維持します。
通常の召喚モンスターと触手にはその層の倍率が適用されます。

### ボス戦の調整箇所

- 能力・経験値・ドロップ・永久効果：`src/data/enemies.ts`
- 行動確率・消費MP・召喚人数・HP閾値：`src/game/ElderTreant.ts` の `ELDER_RULES`
- 部屋・入口封鎖マス：`3-5.ts` の4層 `layout.bossArena`
- ドット絵：`src/render/CaveMonsters.ts`

行動抽選は大落石30％・薙ぎ払い20％・召喚10％・暴風10％。
HP350未満で大ツタ20％が有効になり、HP150未満で縦横同時になります。
残りの枠や条件不成立時は通常攻撃、届かなければ待機します。
暴風・大ツタ・大落石は予告した次のプレイヤー行動後に解決します。
通常召喚は生存10体を上限にし、触手は別枠です。

触手は受けた実ダメージの50％（切り捨て）をボスにも与えます。
触手自身のダメージは軽減しません。薬草1つ＋50％でもう1つ、魔力の雫（小）30％。

### ボムストーン

3-3は各層1／2／3体、3-4は2／3／4体、3-5は3／4／5／6体を固定配置しています。
死亡時のバフ込み攻撃力×150％を保存し、次の行動終了時または攻撃命中で爆発します。
周囲8マスの旅人・精霊・モンスターが対象です。

### テストダンジョン

地域選択の「テストダンジョン」に独立させました。設定は `../test/test-dungeon.ts`。
開始地点から北へ進むと3-5と同じ祭壇、南東へ進むと既存のゴブリン・キングの部屋です。
複数ボス部屋は `layout.bossRooms` で指定できます。戦闘開始時に対象の部屋を有効にし、
ボス撃破後は封鎖した床を戻します。既存セーブには新規配置が追加されないため、
確認時はテストダンジョンを新しく開始してください。
