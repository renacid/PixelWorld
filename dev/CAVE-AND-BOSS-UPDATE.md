# 洞窟・ボス戦・持ち運びセーブの設定

## マップの編集

`dev/dungeon-editor.html` の「洞窟3-1を開く」「森2-5を開く」で編集できます。
現在の下書きを残す場合は先にJSON出力してください。

- 洞窟: `src/stages/cave/3-1.ts` / `3-1.json`。全2層。
- 森: `src/stages/forest/2-5.ts` / `2-5.json`。2層を池の周囲の補給路に変更。1・3層の地形は維持。
- TypeScriptはゲームが使用し、JSONは工房の読み込み・登録済みマップボタンが使用します。変更後は両方を出力してください。
- 出現敵は各層の `layout.enemies` に座標つきで記載しています。

## ボス戦の開始と封鎖

工房の「ボス戦エリア・封鎖マス」で各層の `layout.bossArena` を編集します。

```json
{
  "x": 52, "y": 20, "width": 15, "height": 11,
  "sealTiles": [{ "x": 51, "y": 25 }],
  "wallTile": 4
}
```

`x/y/width/height` は戦闘開始判定と移動可能領域を兼ねます。
範囲に入ると死神を報酬なしで除去し、`sealTiles` 上の敵・味方・アイテム・設置物・罠・床効果・結晶を除去して壁にします。
`wallTile` は地形ID（例: 1=遺跡壁、4=大木、9=土壁）。省略すると1。
ボス本体のマスは封鎖しないでください。旅人の進入マスも避ける構成を推奨します。
戦闘中は移動判定でも旅人を範囲内に制限するため、壁越しの転移・空烈斬でも外へ出られません。
ボス戦開始前は通常の索敵、開始後はエリア内の敵が敵視を維持します。
ボス戦開始後の夜の追加出現は停止します。

## 敵・スキル・罠

- 敵の能力: `src/data/enemies.ts`。トレントの `fireVulnerability: 1` は期限のない炎被ダメージ加算。
- `rootAfterMove: true` は移動した次の敵行動で移動だけを禁止。攻撃は可能。
- 敵スキル: `src/data/enemySkills.ts`。`fallingStrike` と `earthPollen` は別の敵にも再利用可能。
- プレイヤースキル: `src/data/skills.ts`。乱れ突き=`flurry`、落雷=`randomThunder`。
- レベル強化一覧: `src/skills/SkillUpgrades.ts`。通常説明は基本効果、一覧は共通5%成長と特殊強化を表示。
- 大落石: `src/data/traps.ts` の `largeRock`。踏んだ行動で2×2の影を出し、次の行動の敵処理後に落下。
- 夜の追加抽選は固定配置敵の体数を重みに使用。固定配置のないマップでは生成された敵構成を利用。

## 文字列セーブ

停止メニューの「進行状況をセーブ（文字列）」でコピーし、メモなどへ貼り付けて保存します。
トップの「セーブデータを使用」から貼り付けて再開します。繰り返し再開・他端末との共有が可能です。
現在のブラウザの中断データは、読み込みに成功した時点で置き換わります。
コピー欠損のチェック値と進行データの検証を行います。暗号化や改ざん防止を目的とする機能ではありません。

ソース一式からビルド時に互換番号を計算します。更新版では古い文字列を拒否します。
開発中に互換番号を更新したい場合は開発サーバーを再起動してください。
通常の `localStorage` 自動保存はこれまで通りです。
