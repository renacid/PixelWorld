# 洞窟3-2と追加設定の編集案内

## マップ
- 工房の「洞窟3-2を開く」、または `src/stages/cave/3-2.json` の読み込みで編集できます。
- 全層42×38、3層。第1層は住居跡、第2層は地下水脈、第3層は紫の蝶の奥洞です。
- ゲーム側の定義は `src/stages/cave/3-2.ts`。工房で編集後はTypeScriptとJSONの両方を出力して更新してください。
- 第2・3層の宝物庫は任意探索です。出口への主道は施錠していません。
- 宝石・魔導書は各層1個。第2・3層では宝物庫内に配置しています。

## 鉄扉と鍵
- 地形パレットの「鍵付き鉄扉」（地形ID11）を配置します。攻撃では破壊できません。
- 鉄の鍵を持って扉へ進むと、1本消費して開き、そのマスへ移動します。
- 固定鍵箱は `contents: [{ "type": "item", "id": "ironKey" }]`。箱を扉の外から到達できる位置に置いてください。
- 現在の鉄扉は開くと土床（地形ID7）になります。鍵は通常の道具枠を使います。

## 敵・罠・ドロップ
- 大雷蝶の基礎能力・技能一覧・ドロップは `src/data/enemies.ts`。
- 技の確率・MP・倍率は `src/data/enemySkills.ts`。強雷装の `modeBuff` と `requiresMode` は他の敵にも再利用できます。
- 雷・風スキルは4つの独立枠を各1.5%で抽選します。必要なら大雷蝶の `drops` を変更してください。
- 基礎HP30以上の敵は `bookmarkDropChance` が標準0.1。0にすると無効になります。ステージ・階層補正によるHP増加はこの判定に含めません。
- 栞当選後の下級:中級:上級は7:2:1。`src/data/loot.ts` の `MONSTER_BOOKMARK_POOL` で変更できます。
- ストーンスライムシャワーは `src/data/traps.ts` の `stoneSlimeShower`。範囲・最小最大数・出現時HP割合を設定できます。
- 洞窟3-1第2層にはシャワーを2か所固定配置しました。

## 宝石
- HP/MP宝石は第2層1.4倍、第3層以降2倍です。
- 表示と付与を `src/data/gems.ts` の `gemReward` で共通計算します。
